# 因果回路图(Causal Loop Diagram)框架

> 系统动力学 · 因果反馈 · 复杂议题底层结构 · 智库顾问标准模板 · v1.0 · 2026-09-16
> 适配:复杂政策推演 / 经济周期分析 / 组织行为诊断 / 技术演化路径 / 长期趋势建模

---

## 1. 框架定位

**因果回路图(Causal Loop Diagram, CLD)** = 把复杂系统中的**关键变量**画出来,用**带极性的因果链**连接,识别**正/负反馈回路**——定性揭示系统的**底层结构、动态行为、长周期模式**。
**提出者**:Jay Forrester(《Industrial Dynamics》,1961;MIT Sloan 系统动力学学派),由 Peter Senge《第五项修炼》(1990) 推广至管理学。
**用途**:当一个议题的**演化不是线性的、不是单因果的、存在反馈和延迟**时(几乎所有政策、经济、组织、生态议题都符合),需要**先画因果回路图**——看清"哪些回路在驱动系统""哪些会被反噬""延迟在哪""杠杆点在哪"。
**适用阶段**:议题分析第 1 步(底层结构) → 嵌入 PESTLE/波特五力/SWOT/情景规划 全流程,**不是替代它们,而是"补上时间和反馈"的维度**——同样的外部环境,不同的反馈结构,演化路径完全不同。

**核心命题**:
> 90% 的政策失败不是"判断错了",而是**没看见反馈回路**——今天推动的因,3 年后变成自己的果。
> 真正的因果回路分析 = 不只画"X 影响 Y",而是**画清极性、识别回路、定位杠杆、看清延迟**——区分"症状解"(治标)与"根本解"(治本)。
> 工具:不是"列清单",是"画地图"——把每个变量的因果极性画清楚,让**回路结构一目了然**。

**与其他框架的层级关系**:
```
PESTLE          → 识别环境(静态截面)
波特五力         → 识别行业结构(静态截面)
SWOT            → 识别战略匹配(单点)
情景规划         → 识别未来路径(时间维度)
因果回路图       → 识别"为什么是这样演化"(底层结构,时间+反馈)
   ↓
所有其他框架做完后,**必做**因果回路图——找到"杠杆点"和"陷阱回路"
否则再完美的 PESTLE/SWOT/情景规划也会被"看不见的回路"推翻
```

## 2. 核心概念拆解

### 2.1 变量(Variable)

**变量(Variable)** = 系统中的**关键要素**——可以是数量(人口)、状态(信任度)、资源(资金)、感知(预期)。
**原则**:
- 只画**关键变量**,不是全部要素(否则图变蜘蛛网)
- 命名要**可测量 / 可观察**(例:"用户数"✓,"用户满意度"✓,"市场情况"✗)
- 区分**存量(Stock)** 与 **流量(Flow)**——存量是被累积的(库存、人口),流量是单位时间变化(出生率、销售率)
- CLD 阶段**只画关键存量**,流量在后续系统流图(System Dynamics Stock-Flow)再细化

**典型变量类型**:

| 类型 | 例子 | 关注点 |
|------|------|--------|
| **物质存量** | 库存、人口、资本 | 累积速度 |
| **信息/认知存量** | 信任度、预期、品牌资产 | 滞后 + 难改变 |
| **能力存量** | 技能、基础设施、研发能力 | 投资周期长 |
| **关系存量** | 联盟、商誉、社会网络 | 慢但粘性强 |

### 2.2 因果链(Causal Link)

**因果链** = "A 变化 → B 沿同方向/反方向变化"。
**画法**:
```
       +
A ───────► B       (A 增加 → B 也增加)
A ───────► B       (中间标 + 或 -)

       -
A ───────► B       (A 增加 → B 减少)
```

**关键规则**:
- **极性不是相关性**,是**因果方向**——A 涨,B 涨,**不必然** A→B+(可能 B→A+,可能 C→两者)
- 极性判断**只看"直接作用"**——若 A 通过中间变量影响 B,**拆开画**,不要画"间接极性"
- 因果链要**配文字说明**——为什么 A 影响 B?机制是什么?(例:"利率↑ → 投资↓:融资成本升高,资本支出减少")

**常见因果机制**(给极性判断兜底):

| 机制 | 极性 | 例子 |
|------|------|------|
| **资源/激励** | + 或 - 视情况 | 利率↑ → 融资成本↑ → 投资↓ |
| **预期/信号** | + | 央行表态宽松 → 市场预期↑ → 投资↑ |
| **物理限制** | - | 道路容量↑ → 拥堵↓ |
| **学习曲线** | - | 累计产量↑ → 单位成本↓ |
| **网络效应** | + | 用户数↑ → 平台价值↑ → 用户数↑ |
| **竞争/挤出** | - | 某品类销量↑ → 替代品销量↓ |
| **心理/认知偏差** | + | 房价↑ → 投机预期↑ → 房价↑ |

### 2.3 反馈回路(Feedback Loop)

**反馈回路** = 一组闭合的因果链,起点 = 终点,**沿回路走一圈后,起点变量的变化被放大或抵消**。
**两类基本回路**:

| 类型 | 极性 | 行为特征 | 别名 |
|------|------|----------|------|
| **正反馈(Reinforcing, R)** | 回路中 `-` 个数为偶数 | 自我增强、滚雪球、良性/恶性循环 | 增长引擎 / 死亡螺旋 |
| **负反馈(Balancing, B)** | 回路中 `-` 个数为奇数 | 自我调节、趋向目标、抗拒变化 | 稳定器 / 抑制回路 |

**回路命名规范**:
- 用 `R1 / R2 / R3` 标正反馈
- 用 `B1 / B2 / B3` 标负反馈
- 在回路中心标注**回路名称**(例:`R1:马太效应` / `B1:价格-需求均衡`)
- 描述回路:**当 X 增加时,经由 Y、Z,最终导致 X 进一步增加/减少**(正向叙述)

### 2.4 延迟(Delay)

**延迟(Delay)** = 因果链的**作用不是瞬时**,而是经过一段时间才显现。
**画法**:
```
A ─────//────► B
       (双斜杠表示延迟)
```
**或者**:
```
A ───────►(delay)───────► B
```

**关键原则**:
- **几乎所有"软变量"(信任、品牌、政策效果)都带延迟**——硬变量(温度、流量)延迟短,软变量(预期、文化)延迟长
- **延迟 = 政策最容易翻车的地方**——今天推 3 年见效的政策,第 1 年看不到效果就被叫停
- 延迟越长,**振荡风险越大**——决策者倾向"加大剂量"应对短期无反应,3 年后延迟释放出来变成"过量"
- 标注延迟**量级**(短:1-3 月 / 中:1-3 年 / 长:3-10 年 / 超长:10 年+)

### 2.5 杠杆点(Leverage Point)

**杠杆点** = 在回路结构中,**小改变能引发大结果**的位置。
**Donella Meadows 12 级杠杆**(从弱到强):
```
12. 常数/参数(数字)               → 调税率 1%,作用极小
11. 缓冲区大小(库存)              → 多备 1 月库存,作用有限
10. 流-存结构                      → 改变流量,中等作用
9. 延迟长度                       → 缩短反馈延迟,中等作用
8. 负反馈强度                     → 增强稳定器,中等作用
7. 正反馈驱动增长                  → 抑制/驱动增长回路,显著
6. 信息流结构                      → 谁能看到什么,显著
5. 系统规则                       → 改变游戏规则,显著
4. 自组织能力                     → 让系统演化,显著
3. 系统目标                       → 改变目标,深刻
2. 范式/世界观                    → 改变思考方式,深刻
1. 超越范式                      → 跳出框架,最深刻
```

**关键洞察**:**大多数政策只调 12(税率、利率),少数到 9-8(延迟、规则),极少到 5-3(规则、目标)**——杠杆点选错,投入 10 倍力量效果不到 10%。

## 3. 分析步骤(标准 SOP)

### 步骤 1:议题界定 + 系统边界锁定
- 输入:1 句议题边界(例:"某城 2025-2030 房价走势" / "某新能源车企 2026 出海策略")
- 输出:**议题卡**:议题范围 / 时间窗 / 地域 / 关键利益敞口 / **系统边界**(包含哪些变量,排除哪些)
- **关键原则**:**边界决定一切**——同一议题,边界不同,回路结构完全不同
  - 例:"房价"边界=本地市场 vs 全国资金,回路完全不同
- 边界原则:**MECE 但不过度**——8-15 个关键变量,少于 8 看不清回路,多于 15 画成蜘蛛网

### 步骤 2:关键变量识别(MECE + 可观察)
列出**所有可能影响议题演化**的变量 → 合并同类 → 删非关键 → 留下 **8-15 个**。
每个变量填写:
- **名称**(可测量)
- **类型**(物质/认知/能力/关系存量)
- **观察方式**(数据源 / 调查 / 代理指标)
- **变化范围**(短期 / 中期 / 长期才有意义)

**技巧**:
- 从**已发生的事件**倒推——"过去 5 年最大变化是什么" → 倒推变量
- 从**利益相关方**反推——"谁最在意这个议题" → 他们的关注点就是变量
- 从**决策杠杆**反推——"政策工具有哪些" → 反推目标变量

### 步骤 3:因果链画图(极性 + 文字)
对每对变量,问 3 个问题:
1. **A 是否影响 B?** 是 → 画因果链;否 → 不画
2. **极性是 + 还是 -?** 看直接作用机制
3. **是否有延迟?** 估延迟量级

**输出**:**草图 CLD**(含 20-50 条因果链,8-15 个变量)
**反例检查**:
- ❌ "A 影响 B"(不写机制) → 不合格
- ❌ A→B→C 画成 A→C(跳过中间) → 不合格(看不到延迟和极性)
- ❌ 所有因果链都是 + → 几乎肯定有错(负反馈才是系统稳定器)

### 步骤 4:回路识别 + 命名
从草图 CLD 中**找出所有闭合回路**:
- 顺时针或逆时针走,起点 = 终点
- 数 `-` 符号个数:偶数 = R(正反馈),奇数 = B(负反馈)
- 每个回路**命名**(反映核心机制)
- 给回路标优先级:**主导回路(决定系统行为)/ 次要回路(调节)/ 隐性回路(特定条件下激活)**

**回路数量参考**:
- 简单议题:3-5 个回路
- 中等议题:5-8 个回路
- 复杂议题:8-15 个回路
- 超过 15 个 → 边界太宽,需重新锁定

### 步骤 5:主导回路识别 + 行为模式判断
**主导回路** = 在特定时间窗内**决定系统主要行为**的回路。
判断方法:
- 看**当前系统处于什么阶段**(增长 / 饱和 / 衰退 / 振荡)
- 哪个回路**最能解释这个阶段** → 它是主导
- 例:某行业在快速增长 → 找正反馈 R(用户↑ → 网络效应↑ → 用户↑)
- 例:某行业在衰退 → 找负反馈 B(价格↓ → 退出↑ → 供给↓ → 价格↑)失效,或新负反馈(用户↓ → 网络效应↓ → 用户↓)

**行为模式 4 类**:

| 模式 | 主导回路 | 典型场景 |
|------|----------|----------|
| **指数增长** | 强正反馈无抑制 | 早期技术、网络效应、泡沫 |
| **S 型饱和** | 正反馈 + 负反馈(资源限制) | 成熟市场、有限资源系统 |
| **振荡/波动** | 强负反馈 + 长延迟 | 库存周期、房产周期、政策周期 |
| **崩溃/死亡螺旋** | 正反馈(恶性) | 银行挤兑、信任崩塌、生态崩溃 |

### 步骤 6:延迟标注 + 时间维度分析
对每条关键因果链,标注**延迟量级**。
**关键操作**:
- 找出**最长的延迟链**——它们决定系统的**长期行为**
- 找出**短延迟 + 强反馈**的链——容易被**过度调整**(决策者看到短期无反应就加码)
- **时间维度分析**:
  - 1 年内主导哪个回路?
  - 3-5 年主导哪个回路?
  - 10 年+ 主导哪个回路?
- **常见错误**:用短期回路的解去治长期回路的病 → 必然失败

### 步骤 7:杠杆点定位 + 干预策略
按 **Meadows 12 级杠杆**评估每个候选干预点:
- 它影响哪个回路?
- 杠杆等级是多少(12→1)?
- 实施成本 / 政治阻力 / 副作用?

**策略矩阵**:

| 干预类型 | 杠杆等级 | 适用场景 | 风险 |
|----------|----------|----------|------|
| **调参数**(利率、税率) | 12 | 短期微调 | 低 |
| **改变反馈强度**(加监管/补贴) | 7-8 | 中期调整 | 中 |
| **改规则**(游戏规则、产权) | 5 | 结构性改革 | 高 |
| **改目标**(重新定义 KPI) | 3 | 范式转变 | 极高 |
| **改变信息流**(透明化、披露) | 6 | 治理改进 | 中 |
| **缩短延迟**(实时数据、快速反馈) | 9 | 系统提速 | 中 |

**强制要求**:**至少识别 3 个候选杠杆点**,标注等级 + 风险 + 实施路径。

### 步骤 8:动态情景推演 + 检验
基于 CLD 做**情景推演**(与情景规划框架联动):
- 假设外部冲击 X 发生 → 沿回路走 → 6 个月/2 年/5 年/10 年的可能演化
- 对每个推演,**反向回溯**:如果 5 年后看到结果 Y,沿回路倒推,**应该是什么因**?
- 与历史数据**对照**:过去 10 年的实际演化是否被 CLD 预测?如果不一致,**回路结构错了,回去重画**

**输出**:**动态演化剧本**——3-5 个情景 × 4 个时间点 × 主导回路标注。

## 4. 反馈回路类型库(10+ 经典回路)

### 4.1 增长类(R,正反馈)

**R1:网络效应回路**
```
用户数↑ → 平台价值↑ → 新用户吸引力↑ → 用户数↑
```
- 例:微信、淘宝、滴滴
- 关键:网络效应有临界点(突破前慢,突破后指数)

**R2:学习曲线回路**
```
累计产量↑ → 单位成本↓ → 价格竞争力↑ → 销量↑ → 累计产量↑
```
- 例:光伏、锂电池、半导体
- 关键:经验积累是"护城河",但需突破"早期亏损"

**R3:信用扩张回路**
```
房价↑ → 抵押品价值↑ → 信贷能力↑ → 投资/消费↑ → 房价↑
```
- 例:房产周期、金融危机前
- 关键:**金融加速器**,是 2008 次贷危机的核心回路

**R4:马太效应回路(赢家通吃)**
```
优势↑ → 资源获取↑ → 优势进一步↑
```
- 例:平台垄断、头部企业
- 关键:长期看是**死亡螺旋 R**(自我强化到极致崩盘)

**R5:政策预期回路**
```
政策利好→市场预期↑ → 投资↑ → 资产价格↑ → 政策再利好(被现实"验证")
```
- 例:A 股政策市、加密货币周期
- 关键:**自证预言**——预期本身成为因

### 4.2 稳定类(B,负反馈)

**B1:供需均衡回路**
```
价格↑ → 需求↓/供给↑ → 价格↓
```
- 标准经济学均衡
- 限制:短期成立,长期要看弹性

**B2:目标追逐回路**
```
差距↑(目标-现状)→ 行动↑ → 现状↑ → 差距↓
```
- 例:减肥、销售目标、KPI 完成
- 关键:**目标合理**才有效;目标太高 → 行动↑ 但差距不缩小 → 崩溃

**B3:信任修复回路**
```
信任↓ → 沟通投入↑ → 误解减少 → 信任↑
```
- 例:品牌危机、政府公信力修复
- 关键:**慢回路**——信任建立 5 年,崩塌 5 天

**B4:资源约束回路**
```
资源消耗↑ → 可用资源↓ → 消耗速率↓
```
- 例:石油峰值、淡水短缺
- 关键:**物理上限**不可违,负反馈最终主导

### 4.3 振荡类(B + 长延迟)

**B5:库存周期(猪周期、库存周期)**
```
价格↑ → 供给↑(延迟 6-12 月)→ 价格↓ → 供给↓(延迟 6-12 月)→ 价格↑
```
- 例:猪周期、钢铁库存、半导体周期
- 关键:**延迟越长,振幅越大**

**B6:政策反应过度**
```
问题↑ → 政策力度↑(延迟 1-2 年)→ 问题↓ → 政策不退 → 问题↓
↓ (过度)
→ 问题反向↑ → 政策反向↑ → ...
```
- 例:房产调控、宏观调控
- 关键:**政策的"惯性"**是振荡主因

### 4.4 崩溃类(恶性 R)

**R6:银行挤兑回路**
```
提款↑ → 银行流动性↓ → 信心↓ → 提款↑↑
```
- 例:2023 SVB、2008 贝尔斯登
- 关键:**存款保险制度**是切断此回路的关键设计

**R7:生态死亡螺旋**
```
物种↓ → 天敌/平衡↓ → 关键物种↓ → 物种↓
```
- 例:珊瑚白化、亚马逊退化
- 关键:**临界点之后不可逆**

**R8:信任崩塌回路**
```
失信事件↑ → 信任↓ → 合作意愿↓ → 违约↑ → 失信事件↑
```
- 例:婚恋信任、商业合同、政府公信力
- 关键:**社会资本的"死亡螺旋"**比物质资本更难修复

### 4.5 复合类(多个回路耦合)

**R9 + B1 耦合:成长上限**
```
R:用户↑ → 价值↑ → 用户↑ (增长引擎)
B:用户↑ → 资源消耗↑ → 体验↓ → 用户↑减速 (上限)
```
- **关键洞察**:大多数 S 型曲线 = R + B 耦合,B 在某点激活

**R5 + B6 耦合:政策市振荡**
```
R:政策利好 → 预期↑ → 价格上涨
B:价格上涨 → 政策收紧(延迟) → 预期↓ → 价格↓
R(反转):政策收紧过猛 → 预期崩 → 救市政策 → 预期↑
```
- 例:A 股多轮牛熊

## 5. 案例库(3 个经典)

### 案例 1:某城 2025-2030 房价走势分析(CLD 应用)

**议题**:某城 2025-2030 房价走势(均价 3 万 → 涨/跌/横盘?)
**边界**:本市主城区 + 刚需/改善型住宅 + 时间窗 5 年

**步骤 2 关键变量(10 个)**:
1. 房价(目标变量)
2. 居民收入
3. 人口流入
4. 信贷可得性(利率 + 额度)
5. 土地供应
6. 库存(待售面积)
7. 政策预期
8. 投资性需求占比
9. 替代资产回报率(股市/理财/海外房产)
10. 城镇化率

**步骤 3 因果链草图(摘录)**:
```
利率↓(+) → 信贷可得性↑(+) → 购房需求↑(+) → 房价↑
  └─────────────────────────────────────────┘ (R1:金融加速器)

房价↑(+) → 投资性需求↑(+) → 购房需求↑(+) → 房价↑  (R2:投机回路)
  └─────────────────────────────────────────┘

库存↑(-) → 开发商资金压力↑(+) → 降价促销↑(+) → 房价↓
  └─────────────────────────────────────────┘ (B1:库存调节)

人口流入↑(+) → 刚需↑(+) → 购房需求↑(+) → 房价↑
  └─────────────────────────────────────────┘ (R3:基本面支撑)

政策预期↑(+) → 提前购房↑(+) → 短期需求↑(+) → 房价↑  (R4:政策预期,带 1-2 年延迟)
  └─────────────────────────────────────────┘
```

**步骤 4-5 主导回路识别**:
- **当前主导 R1(金融加速器)+ R2(投机回路)** —— 过去 2 年房价涨 30% 主要由此驱动
- **B1(库存调节)被压制** —— 库存已升但开发商扛价,B1 未激活
- **R3(基本面)转弱** —— 人口流入放缓、城镇化接近上限

**步骤 6 延迟分析**:
- R4(政策预期)延迟 1-2 年 → **关键风险点**:政策已转向收紧,但市场反应滞后
- 信贷→房价延迟 3-6 月;供给→房价延迟 12-24 月

**步骤 7 杠杆点(可选干预)**:
- **12 级(调利率)**:短期影响小,治标
- **9 级(缩短延迟)**:增加市场透明度、限制开发商捂盘 → **推荐**
- **7 级(抑制 R2)**:提高二套首付、限售 → **推荐**
- **5 级(改规则)**:房产税试点扩容 → 长期,阻力大
- **3 级(改目标)**:从"稳房价"转向"保障刚需 + 抑制投机" → 根本解

**步骤 8 情景推演**:
| 情景 | 假设 | 5 年后房价 | 主导回路 |
|------|------|------------|----------|
| **基线** | 政策温和收紧,经济平稳 | +10%(慢涨) | R1 弱化 + B1 激活 |
| **乐观** | 政策大幅刺激,人口继续流入 | +40%(快涨) | R1 + R2 + R3 叠加 |
| **悲观** | 政策不力,人口流出,经济下行 | -20%(跌) | R 反转 + R7(信任崩塌) |
| **振荡** | 政策反复 | ±15%(过山车) | B6(政策过度反应)主导 |

**核心洞察**:**不是"涨或跌",而是哪个回路主导**——政策选择决定激活哪个回路。

### 案例 2:某新能源车企 2026 出海策略(组织 + 市场双层 CLD)

**议题**:某车企 2026 出海欧洲,3 年后能否盈利?
**边界**:欧洲市场 + 整车销售 + 时间窗 3 年

**关键回路识别**:

```
R:品牌认知度↑ → 销量↑ → 口碑/服务网络↑ → 品牌认知度↑
B:销量↑ → 售后压力↑ → 投诉↑ → 品牌认知度↓
R:本地化产能↑ → 成本↓ → 价格竞争力↑ → 销量↑
B:本地建厂 → 资本支出↑ → 现金流↓ → 营销投入↓
```

**主导回路**:
- **0-1 年:主导 R(本地建厂→成本↓)** —— 必须先建产能,否则关税吃掉利润
- **1-3 年:主导 R(品牌认知)+ B(售后压力)** —— 销量↑ 但服务跟不上 → 口碑崩塌
- **关键风险**:**售后回路(B)激活过早** → 品牌死了,产能空转

**杠杆点**:
- **6 级(信息流结构)**:实时欧洲用户反馈 → 中国总部 → **推荐** (1 个季度可见效)
- **9 级(缩短延迟)**:在欧洲预建服务网络(成本高但缩短口碑延迟)→ **必须**
- **5 级(改规则)**:与当地经销商深度绑定(规则创新)→ **可选项**

**与情景规划联动**:
- 乐观:欧洲政策友好 + 中国品牌势能强 → 3 年盈利
- 基线:关税中等 + 品牌中性 → 3 年打平
- 悲观:关税壁垒 + 反补贴 → 亏损退出

### 案例 3:某行业 2024-2030 周期判断(库存周期 + 产能周期)

**议题**:某传统行业(例:钢铁、化工)未来 5 年周期判断
**边界**:全国 + 中游加工 + 时间窗 5 年

**核心 CLD**:
```
B5(库存周期,延迟 6-12 月):
价格↑ → 产量↑ → 库存↑ → 价格↓ → 产量↓ → 库存↓ → 价格↑

B6(产能周期,延迟 3-5 年):
价格↑ → 产能投资↑ → 3 年后产能↑ → 供给↑ → 价格↓ → 产能投资↓

R(金融放大):
价格↑ → 抵押品↑ → 信贷↑ → 投资↑ → 产能↑(加速)
```

**关键洞察**:
- **短期看 B5,中期看 B6,长期看金融放大器**
- 2024 现状:B5 已上行(价格涨) → B6 即将激活(产能投资启动)
- **预判**:**2025-2026 价格高位,2027-2028 产能集中释放 → 价格暴跌**
- **杠杆点**:**5 级(产能审批规则)** —— 限制新批产能可延缓 B6 激活,但会扭曲市场

**陷阱**:用 B5(短期涨价)判断趋势,忽视 B6(中期产能)→ 典型 2021 年钢铁股投资者亏损根源

## 6. 陷阱清单(8 大常见错误)

### 陷阱 1:画成"清单"而不是"回路"
- ❌ 列出 30 个变量,因果链稀疏 → 看不出回路
- ✅ 8-15 个变量,**回路密度高**(每变量平均 2-3 条链)

### 陷阱 2:极性判断错误
- ❌ "A↑ → B↑" 实际是 B→A↑(因果倒置)
- ✅ 问 3 遍"为什么" + 找反例检验
- **技巧**:若 A、B 同向变化,**先怀疑是共同因 C**,而不是 A↔B

### 陷阱 3:忽略延迟
- ❌ 所有因果链画成"瞬时" → 看不见振荡、过度反应
- ✅ 强制标注延迟量级,**重点关注延迟 > 1 年的链**

### 陷阱 4:回路命名空洞
- ❌ "增长回路""下降回路"——名字无信息
- ✅ "马太效应""库存调节""金融加速器"——名字反映机制

### 陷阱 5:主导回路识别错误
- ❌ 把"最显眼的回路"当主导
- ✅ 看**当前系统行为**,反推哪个回路最能解释
- **反例**:房价涨 30%,以为是"基本面"(R3),实际是"金融加速器"(R1)主导

### 陷阱 6:杠杆点选错等级
- ❌ 在 12 级(参数)花 90% 精力,忽视 5-3 级(规则/目标)
- ✅ **至少识别 1 个 7 级以上杠杆点**作为主推方案

### 陷阱 7:静态 CLD 而非动态
- ❌ 画完 CLD 就停,不做情景推演
- ✅ **CLD + 4 个时间点 × 3 个情景 = 完整动态剧本**

### 陷阱 8:忽视"反例回路"
- ❌ 只画"想看到的回路",忽视反向证据
- ✅ **强制画"对立回路"** —— 如果我的判断错了,哪个回路应该主导?

## 8. 与其他框架的闭环

```
PESTLE(宏观截面)
   ↓ 转化为 CLD 中的"环境变量"
波特五力(行业结构)
   ↓ 转化为 CLD 中的"竞争回路"
SWOT(战略匹配)
   ↓ 转化为 CLD 中的"优势/劣势变量"
情景规划(时间维度)
   ↓ 转化为 CLD 中的"情景触发条件"
   ↓
因果回路图(底层结构 + 反馈 + 延迟)
   ↓
杠杆点定位 + 干预策略
   ↓
回到 PESTLE/波特/SWOT/情景规划,**验证策略是否真正改变主导回路**
```

**三阶段闭环**:
1. **静态截面阶段**(PESTLE+五力+SWOT):画"是什么"
2. **时间维度阶段**(情景规划):画"会怎样演化"
3. **底层结构阶段**(因果回路图):画"为什么这样演化 + 在哪能撬动"

**关键洞察**:**不画 CLD 的战略分析 = 缺一条腿** ——能看到现状,能看到未来,但看不到**为什么**和**在哪撬动**。
