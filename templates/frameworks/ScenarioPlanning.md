# 情景规划(Scenario Planning)分析框架

> 高不确定性环境下的弹性战略推演 · 智库顾问标准模板 · v1.0 · 2026-09-10
> 适配:长期议题(>5 年)/ 高不确定行业(能源/科技/地缘)/ 战略推演/ 政策沙盘

---

## 1. 框架定位

**情景规划** = 基于"关键不确定性"构建多个**未来情景** → 推演每种情景下的**战略含义** → 形成**对所有情景都鲁棒**的战略组合。
**提出者**:Pierre Wack(Royal Dutch Shell,1971-1972),后由 Peter Schwartz(《The Art of the Long View》,1991)系统化。
**用途**:当**未来不可预测**(高不确定)、**单点预测会失败**(非线性变化)、**战略需要弹性**(避免全押一种未来)时,推演**多情景下的赢/输家**与**战略选项**。
**适用阶段**:议题分析第 2 步(中观层)→ 与波特五力、价值链并列,但**不替代**它们——五力是"看清当下",情景是"看清未来 5-15 年"。

**核心命题**:
> 战略不是"预测最可能的未来然后押注",而是"**识别关键不确定性** → **构造多个可能未来** → **为每个未来都准备**"。
> 真正的情景规划 = 接受"未来不可预测"为前提,目标是**降低被意外击垮的概率**,而不是"猜对"。

**与其他框架的层级关系**:
```
PESTLE  →  波特五力  →  SWOT
(宏观)    (中观)      (微观)
   ↓
情景规划(中观-时间维度)
   ↓
在多个"未来"维度上,套用 PESTLE / 五力 / SWOT
```

## 2. 关键概念拆解

| 概念 | 含义 | 关键问题 | 智库方法论映射 |
|------|------|----------|----------------|
| **关键不确定性**(Critical Uncertainty) | 影响大 + 不确定度高的因素 | 哪些因素**最可能决定**未来走向? | PESTLE 输出(去重/打分) |
| **预定义要素**(Predetermined Elements) | 几乎必然发生的事(趋势已定) | 哪些事情**几乎一定会**发生? | PESTLE 已识别趋势 |
| **情景**(Scenario) | 1 段连贯的"未来叙事" | 在 2 个关键不确定性下,会演化成什么世界? | — |
| **风向标**(Wind Signals / Signposts) | 早期信号指标 | 哪些**早期事件**能告诉我们"正在走向哪个情景"? | — |
| **鲁棒战略**(Robust Strategy) | 在所有情景下都不亏的战略 | 哪些动作**无论哪种未来都对**? | 战略组合 |
| **期权战略**(Option Strategy) | 在某个情景下回报特别高的战略 | 哪些动作**押对了一个未来就大赢**? | 风险投资式组合 |

**关键边界**:
- **预测 vs 情景**:预测说"未来**会**这样",情景说"未来**可能**这样,而且不止一种"。情景规划**不预测**。
- **情景 vs 敏感性分析**:敏感性分析是"如果 X 变 ±10%",情景是"如果 X **整个质变**(高/低两态)"。情景是质变,不是量变。
- **好情景 vs 坏情景**:情景规划**不假设好坏**——每个情景都有赢家和输家,关键是"你是谁"决定输赢。

**情景规划 vs PESTLE 的"未来外推"陷阱**:
> 常见错误:用 PESTLE 的趋势线"线性外推"做预测(经济增长率每年 X%,所以 N 年后是 X*N)。
> 正确做法:PESTLE 识别**所有因素** → 用"影响 × 不确定度"矩阵筛出**2 个关键不确定性** → 围绕它们构建**质变**情景,而不是量变外推。

## 3. 分析步骤(标准 SOP)

### 步骤 1:议题界定
- 输入:1 句议题边界(例:"2030 年中国新能源汽车产业链格局" / "中美科技脱钩下中国 AI 产业前景")
- 输出:**议题卡**:业务范围 / 时间窗(**必须 > 5 年**,否则用 PESTLE 即可) / 地域 / 关键决策点
- **关键原则**:**拒绝**给"短期可预测"的议题做情景规划(浪费);**只对**"非线性、转折点、不确定"的议题使用。

### 步骤 2:全因素扫描(基于 PESTLE)
- 调取 PESTLE / 波特五力的输出作为"全因素池"(一般 20-50 条)
- 每条标注:驱动因子 + 时间窗 + 影响程度(1-5) + 不确定度(1-5)
- **目的**:不漏掉任何"潜在的"关键不确定性

### 步骤 3:关键不确定性筛选
- 用**影响 × 不确定度**矩阵(2 维各 5 分)
- 落在"**高影响 + 高不确定**"象限的 = **关键不确定性候选**(一般 4-8 个)
- **强约束**:**最终只保留 2 个**作为情景轴(2 维才画得出 2x2 矩阵)
- 筛选方法:讨论、专家访谈、文献综述、相关性分析(把强相关的合并)

### 步骤 4:情景轴构建
- 选出的 2 个关键不确定性 = 2 个**轴**
- 每轴定义**两态**(高/低、上行/下行、激进/保守、开放/封闭)
- 命名要**贴议题**(如"中美脱钩程度 × AI 技术突破速度",而不是抽象的"政治 × 技术")
- 2 轴 × 2 态 = **4 个情景**

### 步骤 5:情景叙事(每个情景写 1 段故事)
- 每个情景写 **500-1000 字**的"未来叙事"
- 必须包含:**驱动力(为什么会走到这里)、关键事件时间线、当下的赢家和输家、对议题主体的影响**
- 命名要**形象**(如"双速世界"、"野蛮生长"、"老钱帝国"、"技术奇点")
- **禁止用预测语气**(不说"会",说"在 X 情景下,可能呈现 Y")

### 步骤 6:战略含义分析
- 对每个情景回答 3 个问题:
  1. **谁是赢家**?具备什么能力/资源/位置的主体?
  2. **谁是输家**?哪些主体会被结构性颠覆?
  3. **议题主体(我们)在该情景下应该做什么**?
- 输出:**战略选项表**(4 个情景 × 3 类问题 = 12 个 cell)

### 步骤 7:风向标识别
- 对每个情景找 **3-5 个早期信号**(未来 1-3 年能观察到的)
- 例子:中美脱钩 → 风向标 = 关税清单扩容 / 在美上市中概股退市数 / 半导体设备出口管制
- 输出:**信号监测表**(信号 / 当前值 / 阈值 / 触发哪个情景)

### 步骤 8:战略组合制定
- 把 4 个情景下的战略选项,归为 3 类:
  - **鲁棒战略**:4 个情景下都该做(如"控制成本"、"建立核心能力")——必做
  - **期权战略**:押注 1-2 个情景(如"如果押中情景 A,投资 X 收益 10x")——选择性做
  - **避坑战略**:避免某些动作(4 个情景下都亏的)——**坚决不做**
- 输出:**行动清单**(必做 / 可选 / 不做 三类)

## 5. 与其他框架的搭配

### 5.1 上下游搭配
```
PESTLE  →  情景规划  →  战略推演
(全因素)  (2 关键轴)   (鲁棒+期权)
   ↓          ↓           ↓
外推筛选    情景矩阵     行动清单
```

### 5.2 横向组合
- **PESTLE + 情景规划**:PESTLE 给出"全因素池",情景规划挑出"关键 2 轴"
- **波特五力 + 情景规划**:在每个情景下重新跑一次五力(行业结构会变)
- **SWOT + 情景规划**:在每个情景下重做 SWOT(内部能力不变,外部 O/T 大变)
- **情景规划 + 蒙特卡洛**:情景给"质变框架",蒙特卡洛给"量变概率"——两者互补不替代

### 5.3 决策树组合
```
议题输入
├─ 时间窗 ≤ 3 年? → PESTLE / 波特五力(不需要情景)
├─ 时间窗 3-5 年? → PESTLE + SWOT(线性外推)
├─ 时间窗 5-15 年? → **情景规划** + PESTLE + 波特五力
├─ 时间窗 > 15 年? → 情景规划 + 钻石模型(国家层)
└─ 不确定性极高? → 情景规划 + 鲁棒决策(robust decision making)
```

## 6. 局限与不适用

### 6.1 不适用场景
- **短期决策(< 1 年)**:成本太高、收益太小
- **线性可预测议题**:用 PESTLE 外推即可
- **必须立即执行**的危机:情景规划是"思考"工具,不是"反应"工具
- **单点最优解**问题(优化问题):用算法/数学优化

### 6.2 常见误用
1. **情景当成预测**:把"最可能"的情景当作"会发生"——丧失情景规划本意
2. **情景数太多**(> 4 个):无法管理、无法落地——2x2 是经验最优
3. **轴选错**:选了"低影响 + 高不确定"的因素当轴——情景与决策脱钩
4. **没写叙事只画矩阵**:矩阵只是骨架,叙事才是肉——没叙事 = 没共识
5. **不监测风向标**:情景写完扔一边——失去"动态调整"价值
6. **不强制"避坑战略"**:很多团队只做"必做+可选",忘了识别"坚决不做"——这才是反脆弱的核心

### 6.3 投入产出
- **典型周期**:2-4 周(2-3 人)
- **典型产出**:1 份 30-50 页情景报告 + 1 份行动清单
- **典型成本**:专家访谈 + 文献综述 + 2-3 次工作坊
- **适合节奏**:年度战略复盘 / 5 年规划 / 重大投资决策 / 政策沙盘

## 7. 经典案例(智库库备)

### 案例 1:Royal Dutch Shell · 1970s 石油危机(行业层 · 经典)
- **背景**:1971-1973 年 Shell 内部团队(Pierre Wack 主导)用情景规划推演"OPEC 石油定价权"问题
- **关键不确定性**:OPEC 内部团结度 × 西方需求弹性
- **情景构造**:4 个情景,包括"高油价 + OPEC 团结"——这在 1973 年是"非主流"判断
- **结果**:1973 年石油危机爆发,Shell 因为提前准备(资产重组 + 替代能源投资),比对手(埃克森、BP)更从容,成为 1980s 全球最大石油公司
- **核心教训**:**押注"小概率高影响"情景 = 战略期权**;不为"小概率"做事后必输

### 案例 2:中美科技脱钩 × AI 突破 · 2026 推演(政策/科技层 · 当代)
- **背景**:推演 2030 年中国 AI 产业前景
- **关键不确定性**:**中美脱钩程度** × **AI 技术突破速度**(通用 AI vs 狭义 AI)
- **4 个情景**:
  - A. **双速世界**(深度脱钩 + AGI 突破):全球分裂为 2 个 AI 生态,中国被迫自闭环 → 国产芯片/框架/模型受益
  - B. **新冷战均衡**(深度脱钩 + AGI 迟来):长期对峙,中国成本高但维持追赶 → 政策密集扶持
  - C. **野蛮生长**(有限脱钩 + AGI 突破):全球资本/人才流动继续,AGI 加速所有产业 → 中国应用层爆发
  - D. **老钱帝国**(有限脱钩 + AGI 迟来):回到"互联网时代"格局,中美国力相对稳定 → 渐进式发展
- **战略选项**:
  - 鲁棒(必做):核心算法自研 + 数据合规 + 国际化布局
  - 期权(押 A):押注国产替代链(芯片/光刻机/EDA)
  - 期权(押 C):押注应用层(AI+医疗/教育/制造)
  - 避坑(不做):重资产建海外数据中心(在 A 情景下血亏)
- **风向标**:对华出口管制清单 / 中概股退市数 / 国内大模型参数突破 / 美国对华 AI 投资政策

### 案例 3:SARS 后中国公共卫生体系 · 2003-2020(政策层 · 长周期)
- **背景**:2003 年 SARS 后,中国是否要为"下一次大流行病"做准备?
- **情景构造**:4 个情景,围绕"全球疫情频率 × 国家响应力度"
- **关键判断**:在 2003 年这个时间点,"全球疫情高频率 + 高响应"是**低概率**情景
- **结果**:中国选择"有限准备",CDC 体系重建但投入有限 → 2019 年 COVID 爆发时,**严重被动**
- **核心教训**:**情景规划不是"高概率优先",而是"高影响优先"**——如果押注"小概率高影响"失败了,代价巨大;如果押注"高概率低影响"失败了,代价有限
