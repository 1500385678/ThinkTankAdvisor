## 框架选用决策树

```
议题输入
├─ 时间窗 > 10 年? → STEEP / 钻石模型
├─ 主体 = 国家/区域? → PESTLE / 钻石模型
├─ 主体 = 行业? → 波特五力 / 价值链
├─ 主体 = 企业? → SWOT / 7S / 价值链
├─ 高不确定性? → 情景规划 + PESTLE
└─ 跨主体多目标? → 利益相关方 + 因果回路
```
